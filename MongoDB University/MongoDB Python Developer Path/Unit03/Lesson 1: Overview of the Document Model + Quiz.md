Now that we have the basics out of the way, let’s dig into more detail.  
MongoDB documents are similar to JSON objects. While JSON is great for representing data, MongoDB stores documents in a format called BSON, or Binary JSON.  
Unlike JSON, which is a human-readable text format, BSON is a binary format used for internal storage and transmitting data over the network.   
BSON is an extension of JSON that is designed to be lightweight, traversable, and efficient. It also provides additional data types beyond standard JSON, such as dates, objectID, and timestamps.
