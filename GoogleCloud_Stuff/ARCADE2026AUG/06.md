To complete **Task 5: Load a complex dataset (Customer_List_500.csv)** into your Cloud Spanner database, the fastest method in Cloud Shell is using a **Python script** with the Spanner client library, or converting the CSV into `INSERT` statements using `awk`.

Here are two quick options to get all 500 rows loaded smoothly:

---

### Option 1: Python Script in Cloud Shell (Recommended & Fastest)

1. Open **Cloud Shell** in your Google Cloud Console.
2. Download the CSV file:
```bash
gsutil cp gs://spls/gsp381/Customer_List_500.csv .

```


3. Run the following Python script directly in Cloud Shell to load the data in batches:
```bash
python3 -c "
import csv
from google.cloud import spanner

spanner_client = spanner.Client()
instance = spanner_client.instance('banking-ops-instance')
database = instance.database('banking-ops-db')

with open('Customer_List_500.csv', mode='r') as infile:
    reader = csv.reader(infile)
    # If your CSV contains a header line, uncomment the next line:
    # next(reader, None)

    rows = [tuple(row) for row in reader if row]

# Batch insert in chunks of 100
batch_size = 100
for i in range(0, len(rows), batch_size):
    chunk = rows[i:i + batch_size]
    def insert_chunk(transaction):
        transaction.insert(
            table='Customer',
            columns=('CustomerId', 'Name', 'Location'),
            values=chunk
        )
    database.run_in_transaction(insert_chunk)
    print(f'Inserted rows {i+1} to {i+len(chunk)}')

print('Data import complete!')
"

```



---

### Option 2: Convert CSV to SQL INSERT statements via `awk`

If you prefer using pure SQL/Spanner CLI:

1. Download the CSV in Cloud Shell:
```bash
gsutil cp gs://spls/gsp381/Customer_List_500.csv .

```


2. Generate an SQL insert script:
```bash
awk -F',' '{gsub(/\r/,""); print "INSERT INTO Customer (CustomerId, Name, Location) VALUES (" $1 ", " $2 ", " $3 ");"}' Customer_List_500.csv > insert_customers.sql

```


3. Execute the statements:
```bash
gcloud spanner databases execute-sql banking-ops-db \
  --instance=banking-ops-instance \
  --file=insert_customers.sql

```



---

After running either option, you can verify that all 500 records were successfully inserted:

```bash
gcloud spanner databases execute-sql banking-ops-db \
  --instance=banking-ops-instance \
  --sql="SELECT COUNT(*) FROM Customer;"

```

Once verified, click **Check my progress** on the lab page to score Task 5!

Here is how to adapt that exact Python batch insert script to load **all 500 records** from your `Customer_List_500.csv` file into your database (`banking-ops-instance` and `banking-ops-db`).

---

### Step 1: Open Nano to create/edit the script

In Cloud Shell, run:

```bash
nano batch_insert.py

```

---

### Step 2: Paste the complete code

Delete any existing content and paste the following Python script (it reads the CSV and inserts rows in batches of 100):

```python
import csv
from google.cloud import spanner

INSTANCE_ID = "banking-ops-instance"
DATABASE_ID = "banking-ops-db"

spanner_client = spanner.Client()
instance = spanner_client.instance(INSTANCE_ID)
database = instance.database(DATABASE_ID)

# Read all rows from the CSV file
with open('Customer_List_500.csv', mode='r') as infile:
    reader = csv.reader(infile)
    rows = [tuple(row) for row in reader if row]

# Batch insert in chunks of 100
batch_size = 100
for i in range(0, len(rows), batch_size):
    chunk = rows[i:i + batch_size]
    with database.batch() as batch:
        batch.insert_or_update(
            table="Customer",
            columns=("CustomerId", "Name", "Location"),
            values=chunk
        )
    print(f"Batch inserted rows {i+1} to {i+len(chunk)}")

print("All 500 rows inserted successfully!")

```

> **Note:** Using `batch.insert_or_update` instead of `batch.insert` ensures that if any row was already partially inserted from previous attempts, it won't crash with an `AlreadyExists` error!

---

### Step 3: Save and Exit Nano

1. Press `Ctrl + X`
2. Type `Y`
3. Press `Enter`

---

### Step 4: Run the script

```bash
python3 batch_insert.py

```

---

### Step 5: Verify the count

Once the script finishes, check that all 500 rows are present:

```bash
gcloud spanner databases execute-sql banking-ops-db \
  --instance=banking-ops-instance \
  --sql="SELECT COUNT(*) FROM Customer;"

```

When you see `500`, click **Check my progress** on your lab page!
