You are mixing up two different ways to create environments: Conda and Python's built-in venv. You only need to use one method. [1, 2, 3, 4] 
Here is the quick memory refresh for both methods so you can choose.
## Method 1: Using Conda (Recommended since you have Anaconda)
Conda handles both Python versions and packages. Run these commands in your terminal: [5, 6] 

   1. Create the environment:
   
   conda create --name myenv python=3.10
   
   (Replace myenv with your project name and 3.10 with your version)
   2. Activate it:
   
   conda activate myenv
   
   3. Deactivate when done:
   
   conda deactivate
   
   [7, 8, 9, 10] 

------------------------------
## Method 2: Using Built-in Python venv
This creates a local environment folder inside your project directory. [11] 

   1. Navigate to your project folder:
   
   cd path/to/your/project
   
   [12] 
   2. Create the environment:
   
   python -m venv venv
   
   (The second venv is just the name of the folder it creates) [13, 14] 
   3. Activate it:
   * Windows (Command Prompt): venv\Scripts\activate.bat
      * Windows (PowerShell): venv\Scripts\Activate.ps1
      * macOS / Linux: source venv/bin/activate [15, 16, 17, 18, 19] 
   4. Deactivate when done:
   
   deactivate
   
   [20] 

------------------------------
## Shortcuts inside VS Code
If you do not want to type commands, open your project folder in VS Code, press Ctrl+Shift+P (or Cmd+Shift+P), search for Python: Create Environment..., and just click Conda or Venv. VS Code will handle the commands for you automatically. [21, 22]
